# Fictional Policy: Debit and Credit Card Disputes

Customers should report an unfamiliar card transaction as soon as possible using the official banking app or verified customer-support channel.

A dispute request should include the transaction date, amount, merchant name if available, and a short description of why the transaction is disputed.

Submitting a dispute does not guarantee a refund; the bank reviews the evidence and communicates the outcome through an official channel.

Customers should never send a full card number, PIN, password, or OTP in an unsecured message.
